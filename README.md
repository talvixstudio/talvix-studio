# Talvix Studio

### Sites que fazem sua empresa parecer do tamanho que ela é.

A **Talvix Studio** é um estúdio digital especializado na criação de sites modernos, estratégicos e personalizados para empresas que querem elevar sua presença digital.

Unimos **design, estratégia e desenvolvimento** para criar experiências digitais que transmitam profissionalismo, confiança e valor.

## Sobre o projeto

Este repositório contém o **site oficial da Talvix Studio**.

O projeto foi desenvolvido com foco em:

- Design premium e moderno
- Experiência totalmente responsiva
- Performance e velocidade
- Experiência do usuário
- Identidade visual consistente
- Navegação fluida
- Conversão de visitantes em potenciais clientes

## Tecnologias

O projeto utiliza tecnologias modernas de desenvolvimento web:

- React
- TypeScript
- CSS
- TanStack
- Git & GitHub
- Vercel

## Desenvolvimento

O projeto utiliza um fluxo de desenvolvimento integrado entre:

**Lovable → GitHub → Vercel**

As alterações do projeto são versionadas neste repositório e publicadas através da Vercel.
